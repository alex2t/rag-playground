### Ostrander Client Portal

- **Service:** Experience Cloud Portal Build
- **Start date:** 2022-02-07
- **End date:** 2022-05-16
- **Team:** Saoirse Kettleby, Everett Nakamura-Boyle, Rafferty Okeke

**Summary:** Built a branded Experience Cloud portal where clients view matter status and submit documents securely. The build included a sharing model that separates each client's matters.

**Objectives:**

- Give clients secure access to matter status and document requests
- Apply a sharing model that isolates each client's data
- Pass an accessibility review against WCAG 2.1 AA

**Outcome:** The portal launched to clients on the project end date and an admin guide was handed to the firm's IT team.

**Metrics:**

- Status-update emails sent by paralegals fell from 520 to 190 per month, a 63.5% reduction
- 2 portal user types configured
- 6 page templates delivered
