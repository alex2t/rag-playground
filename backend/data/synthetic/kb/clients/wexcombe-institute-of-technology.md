## Projects

### Wexcombe Applicant Portal

- **Service:** Experience Cloud Portal Build
- **Start date:** 2019-01-14
- **End date:** 2019-04-29
- **Team:** Saoirse Kettleby, Aoife Brannigan

**Summary:** Built an Experience Cloud portal where prospective students track applications and raise enquiries. The build included self-registration, a sharing model and Flow-driven forms.

**Objectives:**
- Give applicants self-service access to application status
- Offer case submission and knowledge pages for common enquiries
- Pass an accessibility review against WCAG 2.1 AA

**Outcome:** The portal launched ahead of the autumn application cycle with an admin guide handed to the admissions team.

**Metrics:**
- Enquiries resolved through self-service rose from 31.0% to 52.4%, a gain of 21.4 percentage points
- 3 portal user types configured
- 4 Flow-driven forms built

### Wexcombe Student Services Rollout

- **Service:** Service Cloud Rollout
- **Start date:** 2020-01-13
- **End date:** 2020-04-06
- **Team:** Tobias Wainwright, Aoife Brannigan, Dashiell Pruitt

**Summary:** Rolled out Service Cloud for Wexcombe's student services office, covering case management, routing and a knowledge base. Omni-Channel routing was set up for email and web chat.

**Objectives:**
- Move student enquiry tracking into Service Cloud
- Route cases through 4 queues by enquiry type
- Publish student-facing knowledge articles

**Outcome:** Student services went live on Service Cloud and hypercare ticket volumes stayed within the monthly allowance.

**Metrics:**
- Hypercare averaged 52 support tickets per month
- Average case resolution time fell from 4.8 days to 2.4 days, a 50.0% reduction
- 4 case queues configured

### Wexcombe Enrolment Assistant

- **Service:** Agentforce Agent Design
- **Start date:** 2024-09-09
- **End date:** 2024-11-11
- **Team:** Odalys Fenwick, Julien Archambault, Tobias Wainwright

**Summary:** Designed and tested an Agentforce agent that answers enrolment and fee enquiries for prospective and current students. The agent was built around four topics with escalation rules to student services staff.

**Objectives:**
- Define 4 agent topics for enrolment, fees, deadlines and accommodation
- Write guardrails and escalation rules
- Test the agent against 120 scripted conversations

**Outcome:** The agent passed its scripted test plan after one tuning cycle and a post-launch performance review was delivered.

**Metrics:**
- Agent passed 108 of 120 scripted conversations after tuning, a 90.0% pass rate
- 4 agent topics configured
- 6 standard actions configured
