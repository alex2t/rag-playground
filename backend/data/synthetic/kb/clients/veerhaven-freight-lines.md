### Veerhaven Security Review

- **Service:** Shield Security and Compliance Review
- **Start date:** 2020-11-02
- **End date:** 2020-12-14
- **Team:** Wilhelmina Oyelaran, Idris Venkataram

**Summary:** Reviewed Veerhaven's Salesforce orgs against Shield capabilities and delivered a rated findings report. The work covered Event Monitoring dashboards, Field Audit Trail setup and a Platform Encryption design.

**Objectives:**
- Rate security findings across 3 Salesforce orgs
- Set up Field Audit Trail on customer and shipment objects
- Deliver a remediation roadmap

**Outcome:** The findings report and roadmap were presented to Veerhaven's security and IT teams on the project end date.

**Metrics:**

### Veerhaven Shipment Integration

- **Service:** MuleSoft Integration Blueprint
- **Start date:** 2021-09-13
- **End date:** 2021-11-29
- **Team:** Lorcan Mulvihill, Idris Venkataram, Aoife Brannigan

**Summary:** Built an API-led integration layer on MuleSoft connecting Salesforce with Veerhaven's transport management system, customs filing platform and billing system. The project included error handling, retry design and a monitoring dashboard.

**Objectives:**
- Connect Salesforce to 3 external systems
- Implement 6 integration flows for shipment, customs and invoice data
- Hand over a runbook and monitoring dashboard

**Outcome:** All six flows were deployed to production and the operations team completed knowledge transfer sessions.

**Metrics:**
- Manual re-keying of customs data fell from 14 hours to 3 hours per week, a 78.6% reduction
- 6 integration flows implemented
- 3 external systems connected
