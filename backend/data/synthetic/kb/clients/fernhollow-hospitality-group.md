## Projects

### Fernhollow Circle Journeys

- **Service:** Marketing Cloud Journey Setup
- **Dates:** 2021-02-08 to 2021-04-05
- **Team:** Matthias Eklund, Dashiell Pruitt

**Summary:** Set up Marketing Cloud for Fernhollow's loyalty programme with automated welcome, stay and win-back journeys. Guests were segmented by stay history and sender authentication was configured for the booking domain.

**Objectives:**
- Build 3 loyalty journeys in Journey Builder
- Segment guests by stay history
- Configure sender authentication and unsubscribe handling

**Outcome:** The loyalty journeys were live by the project end date and the marketing team took over reporting on opens, clicks and conversions.

**Metrics:**
- Repeat-booking email conversion rose from 2.1% to 3.4%, a gain of 1.3 percentage points
- 3 journeys configured
- 6 responsive email templates delivered

### Fernhollow Guest Services Rollout

- **Service:** Service Cloud Rollout
- **Dates:** 2022-01-17 to 2022-03-28
- **Team:** Tobias Wainwright, Dashiell Pruitt, Rafferty Okeke

**Summary:** Rolled out Service Cloud for Fernhollow's central guest services team, covering case management, queues and a knowledge base. Omni-Channel routing was set up for email and web chat.

**Objectives:**
- Centralise guest complaint and request tracking in Service Cloud
- Set up 3 case queues with assignment rules
- Migrate guest policy articles into a knowledge base

**Outcome:** Guest services went live on Service Cloud and completed 60 days of hypercare within the monthly ticket allowance.

**Metrics:**
- Hypercare averaged 41 support tickets per month
- Average case resolution time fell from 26 hours to 15 hours, a 42.3% reduction
- 98 knowledge articles migrated

### Fernhollow Guest Profile Unification

- **Service:** Data Cloud Foundations
- **Dates:** 2023-08-14 to 2023-10-30
- **Team:** Naveen Castellanos, Thandiwe Moyo-Sinclair

**Summary:** Built a Data Cloud foundation that brings Fernhollow's booking, loyalty and survey data into unified guest profiles. Identity resolution rules and segment activation to Marketing Cloud were included.

**Objectives:**
- Ingest 5 data streams covering reservations, loyalty, point of sale and surveys
- Unify guest identities with a documented ruleset
- Activate 3 guest segments

**Outcome:** Unified guest profiles went live and segments were activated to Marketing Cloud by the project end date.

**Metrics:**
- Guest profile match rate rose from 61.0% to 88.3%, a gain of 27.3 percentage points
- 5 data streams configured
- 3 segments activated

### Fernhollow Reservation Assistant

- **Service:** Agentforce Agent Design
- **Dates:** 2025-02-10 to 2025-04-07
- **Team:** Odalys Fenwick, Julien Archambault, Dashiell Pruitt

**Summary:** Designed and tested an Agentforce agent that handles reservation changes and amenity questions for hotel guests. The agent has defined topics and guardrails with escalation to guest services staff.

**Objectives:**
- Define 3 agent topics for reservation changes, amenities and local information
- Write escalation rules for complaints
- Test the agent against 120 scripted conversations

**Outcome:** The agent completed sandbox testing and one tuning cycle, and a post-launch performance review was delivered.

**Metrics:**
- Pilot escalation rate was 17.0%
- Agent passed 105 of 120 scripted conversations after tuning, an 87.5% pass rate
- 3 agent topics configured
