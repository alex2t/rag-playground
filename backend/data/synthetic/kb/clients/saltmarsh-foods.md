## Projects

### Saltmarsh Order Integration

- **Service:** MuleSoft Integration Blueprint
- **Start date:** 2017-11-06
- **End date:** 2018-01-15
- **Team:** Lorcan Mulvihill, Idris Venkataram

**Summary:** Designed and built an API-led integration layer on MuleSoft connecting Salesforce with Saltmarsh's ERP, warehouse system and carrier booking platform. The work included error handling, retry design and a monitoring dashboard.

**Objectives:**
- Connect Salesforce to 3 external systems through system, process and experience APIs
- Implement error handling and retry logic for order flows
- Hand over a runbook and monitoring dashboard

**Outcome:** Five integration flows were deployed to production and the operations team received knowledge transfer sessions on the runbook.

**Metrics:**
- Order synchronisation latency fell from 45 minutes to 4 minutes, a 91.1% reduction
- 5 integration flows implemented
- 3 external systems connected

### Saltmarsh Distributor Portal

- **Service:** Experience Cloud Portal Build
- **Start date:** 2018-09-10
- **End date:** 2018-12-17
- **Team:** Saoirse Kettleby, Aoife Brannigan

**Summary:** Built a branded Experience Cloud portal where food-service distributors check order status and raise cases. The build covered self-registration, a sharing model and Flow-driven forms.

**Objectives:**
- Give distributors self-service order status and case submission
- Apply a sharing model so each distributor sees only its own accounts' data
- Pass an accessibility review against WCAG 2.1 AA

**Outcome:** The portal launched for distributors on the project end date with an admin guide handed to Saltmarsh's digital team.

**Metrics:**
- Distributor order-status calls fell from 640 to 410 per month, a 35.9% reduction
- 3 portal user types configured
- 8 page templates delivered

### Saltmarsh Recipe Newsletter Journeys

- **Service:** Marketing Cloud Journey Setup
- **Start date:** 2019-09-23
- **End date:** 2019-11-18
- **Team:** Matthias Eklund, Aoife Brannigan

**Summary:** Set up Marketing Cloud for Saltmarsh's consumer recipe programme, with sender authentication, subscriber imports and three automated journeys. Audiences were split into segments by dietary preference.

**Objectives:**
- Configure sending domain and sender authentication
- Build 3 Journey Builder journeys for welcome, recipe and re-engagement emails
- Segment subscribers by dietary preference

**Outcome:** All three journeys were live by the project end date and tracking reports on opens, clicks and conversions were handed to the marketing team.

**Metrics:**
- Email open rate rose from 21.4% to 27.9%, a gain of 6.5 percentage points
- 4 audience segments created
- 6 responsive email templates delivered

### Saltmarsh Customer Data Foundation

- **Service:** Data Cloud Foundations
- **Start date:** 2023-02-20
- **End date:** 2023-05-08
- **Team:** Naveen Castellanos, Thandiwe Moyo-Sinclair, Idris Venkataram

**Summary:** Established a Data Cloud foundation that unifies Saltmarsh's consumer and distributor contact data from five sources. The project included identity resolution rules and activation of segments to Marketing Cloud.

**Objectives:**
- Ingest 5 data streams into Data Cloud
- Resolve duplicate customer identities with a documented ruleset
- Activate 3 segments to Marketing Cloud

**Outcome:** Unified profiles went live and three segments were activated to Marketing Cloud by the project end date.

**Metrics:**
- Duplicate customer profiles fell from 18,400 to 6,900, a 62.5% reduction
- 5 data streams configured
- 3 segments activated
