## Projects

### Halcyon Patient Access Rollout

- **Service:** Service Cloud Rollout
- **Dates:** 2014-02-24 to 2014-05-02
- **Team:** Tobias Wainwright, Idris Venkataram
- **Summary:** Service Cloud was rolled out to the patient access contact centre, with queues for appointments, referrals and billing. A knowledge base supports agents answering routine patient questions.

**Objectives**
- Track every appointment request as a case
- Shorten response time on appointment requests

**Outcome:** The patient access team handles appointment and referral requests in Service Cloud.

**Metrics**
- 3 case queues configured
- 94 knowledge articles migrated
- Average time to answer appointment-request cases reduced from 7.4 hours to 3.2 hours, a 56.8% reduction
- Hypercare tickets peaked at 44 in a single month

### Halcyon Referral Portal

- **Service:** Experience Cloud Portal Build
- **Dates:** 2020-02-03 to 2020-05-15
- **Team:** Saoirse Kettleby, Tobias Wainwright, Dashiell Pruitt
- **Summary:** An Experience Cloud portal was built for patients, referring physicians and partner clinics. Flow-driven forms let referring physicians submit referrals online, and sharing rules limit each user to their own cases.

**Objectives**
- Move referral submission from fax and phone to the portal
- Control visibility of each user's cases

**Outcome:** The portal launched with three user types, and referral submissions moved online.

**Metrics**
- 3 portal user types and 8 page templates delivered
- 5 Flow-driven forms built
- Online referral forms increased from 340 to 1,120 per month, a 229.4% increase

### Halcyon Shield Security Review

- **Service:** Shield Security and Compliance Review
- **Dates:** 2020-09-14 to 2020-10-23
- **Team:** Wilhelmina Oyelaran, Idris Venkataram
- **Summary:** Two Halcyon orgs containing patient access data were reviewed against Shield capabilities. The work covered event log analysis, an encryption design and a Field Audit Trail policy.

**Objectives**
- Assess protection of patient-related data
- Establish audit trails on sensitive objects

**Outcome:** The security officer accepted the findings report and the remediation roadmap.

**Metrics**
- 2 orgs reviewed
- 27 findings rated, 8 of them rated high
- Platform Encryption designed for 16 fields and Field Audit Trail set up on 9 objects

### Halcyon Patient Access Agent

- **Service:** Agentforce Agent Design
- **Dates:** 2024-10-14 to 2024-12-27
- **Team:** Odalys Fenwick, Julien Archambault, Tobias Wainwright
- **Summary:** An Agentforce agent was designed to answer appointment preparation, location hours and billing questions. Guardrails make the agent decline clinical advice and escalate to staff.

**Objectives**
- Answer routine patient access questions automatically
- Prevent the agent from giving clinical advice

**Outcome:** The agent launched after a sandbox tuning cycle, with escalation to the patient access queue.

**Metrics**
- 4 agent topics and 6 standard actions configured
- 106 of 120 scripted conversations passed, an 88.3% pass rate
