# MuleSoft Integration Blueprint

Larkspur Cloud Partners offers the MuleSoft Integration Blueprint service. It designs and builds an API-led integration layer that connects Salesforce with a client's back-office systems on MuleSoft.

## Service Overview

| Attribute | Detail |
|---|---|
| Firm | Larkspur Cloud Partners |
| Salesforce product | MuleSoft |
| Lead | Lorcan Mulvihill |
| Launch year | 2017 |
| Typical duration | 9 weeks |
| Pricing model | Capped time and materials |
| Price | 72,400 USD |

## Deliverables

- Integration landscape assessment
- API-led architecture blueprint
- Up to 6 implemented integration flows
- Error handling and retry design
- Runbook and monitoring dashboard
- Knowledge transfer sessions

## Scope

### Included

- Anypoint Platform environment setup
- System, process and experience API layering
- Connections to up to 3 external systems
- Basic API policies for authentication and throttling
- Deployment to one production environment

### Excluded

- Modification of legacy systems
- Ongoing integration support after handover
- Data cleansing of source systems

## Client Prerequisites

- MuleSoft Anypoint licences in place
- API documentation for each connected system
- A technical contact at each connected system
