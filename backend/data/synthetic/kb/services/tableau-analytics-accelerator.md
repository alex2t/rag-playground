# Tableau Analytics Accelerator

Larkspur Cloud Partners offers the Tableau Analytics Accelerator service. It delivers a focused set of Tableau dashboards on certified data sources, with training so that client analysts can extend them.

## Service Overview

| Attribute | Detail |
|---|---|
| Firm | Larkspur Cloud Partners |
| Salesforce product | Tableau |
| Pricing model | Fixed fee |
| Price | 31,800 USD |
| Typical duration | 6 weeks |
| Launch year | 2020 |
| Lead | Fionnuala Darragh |

## Deliverables

- Reporting requirements document
- Up to 3 published dashboards
- Up to 2 certified data sources
- Tableau Cloud site configuration with user groups
- Dashboard style guide and training session

## Scope

### Included

- Connection to Salesforce and up to one additional data source
- Row-level security for up to 3 user groups
- Extract refresh scheduling
- Two training sessions for analysts

### Excluded

- Data warehouse build
- Tableau Server infrastructure installation
- Custom embedded analytics development

## Client Prerequisites

- Tableau licences purchased before kickoff
- Read access to source data
- A business analyst nominated as dashboard owner
