# Sales Cloud Implementation

Larkspur Cloud Partners offers Sales Cloud Implementation, a service that configures Sales Cloud for a mid-market sales team, covering lead-to-opportunity process design, pipeline reporting and rep onboarding.

## Service Overview

| Attribute | Detail |
|---|---|
| Service name | Sales Cloud Implementation |
| Salesforce product | Sales Cloud |
| Pricing model | Fixed fee |
| Price | 58,500 USD |
| Typical duration | 12 weeks |
| Launch year | 2012 |
| Lead | Calista Brandt |

## Deliverables

- Sales process design workbook
- Configured Sales Cloud org
- Pipeline and forecast dashboards
- Data migration of up to 50,000 lead, account and contact records
- Role-based training sessions
- Go-live readiness checklist

## Scope

### Included

- Up to 3 sales process variants by record type
- Lead assignment and opportunity stage configuration
- Up to 12 standard reports and 3 dashboards
- Profile and permission set setup for up to 40 users
- Two weeks of post-go-live support

### Excluded

- Custom Apex development
- Integrations with external systems
- CPQ or billing configuration

## Client Prerequisites

- A named business owner with decision authority
- CSV exports of current lead, account and contact data
- Sales Cloud licences purchased before kickoff
