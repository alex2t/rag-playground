# Shield Security and Compliance Review

Larkspur Cloud Partners offers the Shield Security and Compliance Review. The service reviews a client's Salesforce orgs against Shield capabilities and delivers a rated findings report with a remediation roadmap.

Shield is a Salesforce product. The service lead is Wilhelmina Oyelaran.

## Service Overview

| Item | Detail |
|---|---|
| Salesforce product | Shield |
| Pricing model | Fixed fee |
| Price | 31,200 USD |
| Typical duration | 5 weeks |
| Launch year | 2020 |
| Lead | Wilhelmina Oyelaran |

## Deliverables

- Security findings report with risk ratings
- Event Monitoring dashboards
- Field Audit Trail policy
- Platform Encryption design for up to 20 fields
- Remediation roadmap

## Scope

### Included

- Review of up to 3 Salesforce orgs
- Event log analysis covering 30 days
- Field Audit Trail setup on up to 10 objects
- Walkthrough session with security stakeholders

### Excluded

- Penetration testing
- Formal compliance audits such as SOC 2
- Remediation work beyond Shield configuration

## Client Prerequisites

- Shield licences purchased before kickoff
- Admin access to the orgs under review
- A security contact named by the client
