# Experience Cloud Portal Build

**Firm:** Larkspur Cloud Partners
**Service lead:** Saoirse Kettleby

## Overview

Builds a branded customer or partner portal on Experience Cloud with self-service cases, knowledge and secure record sharing.

Experience Cloud is the Salesforce product used for this service.

## Commercial terms

| Item | Detail |
|---|---|
| Pricing model | Fixed fee |
| Price | 63,200 USD |
| Typical duration | 13 weeks |
| Launch year | 2018 |

## Deliverables

- Portal requirements and user journey map
- Branded Experience Cloud site
- Up to 8 page templates
- Self-service case and knowledge pages
- Sharing and visibility model
- Launch checklist and admin guide

## Scope

### Included

- Profiles for up to 3 portal user types
- Branding using client-supplied style assets
- Login and self-registration setup
- Up to 5 Flow-driven forms
- Accessibility review against WCAG 2.1 AA

### Excluded

- Custom Lightning component development
- Single sign-on with external identity providers
- Content writing and photography

## Client prerequisites

- Experience Cloud licences purchased before kickoff
- Brand guidelines and logo files
- A defined list of portal user types
