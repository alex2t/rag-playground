# Marketing Cloud Journey Setup

Marketing Cloud Journey Setup is a service offered by Larkspur Cloud Partners. It sets up Marketing Cloud foundations and builds automated customer journeys with segmented audiences and tracked email performance.

## Service Overview

| Attribute | Detail |
|---|---|
| Salesforce product | Marketing Cloud |
| Pricing model | Fixed fee |
| Price | 38,900 USD |
| Typical duration | 7 weeks |
| Launch year | 2019 |
| Lead | Matthias Eklund |

## Deliverables

- Journey strategy document
- Up to 3 configured Journey Builder journeys
- Up to 6 responsive email templates
- Data extension and subscriber import setup
- Deliverability and sender authentication checklist

## Scope

### Included

- Sending domain and sender authentication setup
- Preference and unsubscribe handling
- Audience segmentation for up to 4 segments
- Tracking reports on opens, clicks and conversions

### Excluded

- SMS, push or WhatsApp channels
- Copywriting and creative design
- Ongoing campaign management

## Client Prerequisites

- Marketing Cloud account provisioned
- A subscriber list with documented consent
- DNS access for the sending domain
