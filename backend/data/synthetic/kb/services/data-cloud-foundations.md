# Data Cloud Foundations

Data Cloud Foundations is a service offered by Larkspur Cloud Partners. It establishes a working Data Cloud foundation, from source ingestion and identity resolution to the activation of customer segments.

Data Cloud is a Salesforce product for unifying customer data from multiple sources into profiles that can be used for segmentation and activation.

## Deliverables

- Data source inventory and ingestion plan
- Up to 5 configured data streams
- Data model mapping document
- Identity resolution ruleset
- Up to 3 activated segments

## Scope

### Included

- Unified profile design
- Up to 5 data streams from batch or API sources
- Calculated insights for up to 4 metrics
- Activation to one destination

### Excluded

- Custom machine learning models
- Marketing journey build
- Data warehouse design

## Client Prerequisites

1. Data Cloud provisioned in the client's production org
2. A data owner named for each source system
3. Sample extracts from every source in scope
