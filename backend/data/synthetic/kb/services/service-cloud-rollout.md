# Service Cloud Rollout

Service Cloud Rollout is a service from Larkspur Cloud Partners. It rolls out Service Cloud for a support team, including case management, routing, knowledge and post-launch hypercare.

Service Cloud is Salesforce's customer service product.

## Service Overview

| Item | Detail |
|---|---|
| Firm | Larkspur Cloud Partners |
| Salesforce product | Service Cloud |
| Pricing model | Fixed fee |
| Price | 57,900 USD |
| Typical duration | 11 weeks |
| Launch year | 2013 |
| Lead | Tobias Wainwright |

## Deliverables

- Support process map
- Configured Service Cloud org with case, queue and entitlement setup
- Email-to-case and web-to-case configuration
- Knowledge base with up to 150 migrated articles
- Agent training materials
- Hypercare summary report

## Scope

### Included

- Up to 4 case queues with assignment rules
- Omni-Channel routing for up to 2 channels
- Post-go-live hypercare covering up to 60 support tickets per month for 60 days
- Service console layout for up to 3 agent profiles
- Up to 5 service reports

### Excluded

- Telephony or CTI integration
- Custom Apex development
- Field service scheduling

## Client Prerequisites

- Service Cloud licences purchased before kickoff
- Exported case history from the legacy help desk
- A support manager available 6 hours per week
